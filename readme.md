# steam-config-nix

Declaratively manage Steam and your library on NixOS or Home Manager.

- Launch options
- Systemd integration
- Compatibility tools
- Proton prefix locations
- Beta branches, languages & update behavior
- Library artwork & desktop entries
- Winetricks verbs
- Game files & mods
- Non-Steam apps

> [!NOTE]
> By default, changes are not applied until Steam is closed. This is configurable with `onSteamRunning`, which can also close Steam for you. See [Applying changes](https://different-name.github.io/steam-config-nix/configuration.html#applying-changes).

See [Installation](https://different-name.github.io/steam-config-nix/installation.html) to add the module and [Quickstart](https://different-name.github.io/steam-config-nix/quickstart.html) for a working example. Each [guide](https://different-name.github.io/steam-config-nix/) covers one feature, or see the [Options Reference](https://different-name.github.io/steam-config-nix/options.html) for everything.
