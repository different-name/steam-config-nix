# steam-config-nix

Declaratively manage Steam and your library on NixOS or Home Manager.

- Launch options
- Systemd integration
- Compatibility tools
- Proton prefix locations
- Beta branches, languages & update behaviour
- Library artwork & desktop entries
- Winetricks verbs
- Game files & mods
- Non-Steam apps

<!-- prettier-ignore -->
> [!NOTE]
> By default, changes are not applied until Steam is closed. This is configurable with `onSteamRunning`, which can also close Steam for you. See [How changes are applied](https://different-name.github.io/steam-config-nix/docs/applying-changes/).

Start with
[Getting started](https://different-name.github.io/steam-config-nix/docs/), or
search [all options](https://different-name.github.io/steam-config-nix/search/).
