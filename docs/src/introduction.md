# steam-config-nix

Declaratively manage Steam and your library on NixOS or Home Manager.

- Launch options
- Systemd integration
- Compatibility tools
- Beta branches, languages & update behavior
- Library artwork & desktop entries
- Winetricks verbs
- Game files & mods
- Non-Steam apps

> [!NOTE]
> By default, changes are not applied until Steam is closed. This is configurable with `onSteamRunning`, which can also close Steam for you. See [Applying changes](./configuration.md#applying-changes).

See [Installation](./installation.md) to add the module and [Quickstart](./quickstart.md) for a working example. Each guide covers one feature, or see the [Options Reference](./options.md) for everything.
